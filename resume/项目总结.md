# 项目总结（第一人称，约 600 字）

这个项目是我为求职准备的运动控制作品集：用 Python 在没有真实驱动器的条件下，仿真了龙门双轴同步与电子凸轮飞剪两类最典型的多轴控制场景。

起点是一个问题：龙门两侧的伺服轴为什么会不同步？从位置环方程可推出恒速跟随误差 e=v/Kp——两台电机的位置环增益受编码器、丝杠导程和驱动器参数共同影响，天然存在几个百分点的差异，于是同步偏差 Δ=act1−act2=v/Kp2−v/Kp1 出现。为了让这个机理在代码里真实发生，我把虚拟伺服轴做成与真实系统同构：梯形/S 曲线规划器生成指令，一阶闭环模型产生滞后，脉冲当量量化指令，增益和负载可按轴独立配置。自测试中恒速跟随误差精确等于 v/Kp，验证了模型的正确性。

同步方案我选择交叉耦合同步：把两轴实际位置之差对称反馈到两轴目标上。我推导出稳态偏差公式 Δ*=v(1/Kp2−1/Kp1)/(1+2Kcc)，说明补偿能把偏差压缩为开环值的 1/(1+2Kcc)。批量实验跑完补偿开/关乘失配 5%~30% 共八种组合，P95 同步偏差全部下降约 80%，与理论吻合；30% 失配加 2mm 阈值时无补偿触发报警停机、有补偿正常完成，展示了真实龙门的超差联锁逻辑。

电子凸轮部分按飞剪工艺自动生成 256 点凸轮表：待机、加速追赶、同步落刀、快速返回一个循环，关键设计规则是表中同步段斜率必须等于定长 L，切刀期间刀带才严格同速；支持在周期边界换表模拟换产。带速扫描实验中，700mm/s 带速下同步段速度误差均值只有 0.65mm/s，循环节拍与理论值 L/v 的最大偏差不足 1ms。

最后我用 Flask 加 ECharts 做了在线看板，能实时修改失配度和补偿开关并立即看到曲线变化，还用 Canvas 做了输送带与切刀联动的回放动画。全部指标都诚实标注为仿真验证值，我也清楚真机项目还需要完成惯量辨识、增益整定和谐振抑制等驱动器调试工作。
